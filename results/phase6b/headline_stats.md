## Notes

- **Miss intervals:** Wilson score interval (95 %); with 0 misses, the exact one-sided 95 % upper bound `1 − 0.05^(1/n)` (≈ 3/n).
- **Runs disagree more than counting noise allows** when the per-run ratios fall outside each other's intervals (e.g. A under `rboth`). Then the pooled interval understates the uncertainty; quote the per-run range.
- **Block intervals:** bootstrap of the median over pooled blocks (10,000 resamples). Blocks in one run are correlated, so this interval is optimistic.
- **Ratio range:** Linux bootstrap interval divided by Config C's worst and best block (C has 1 block per run, 2 per tier).
